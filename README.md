# 物流费用试算器

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

保价、代收货款、送货上门不再写在备注里，而是报价单上的费用明细，改来改去也能看清哪几项真的收了钱。

## 明细规则（`src/domain/`）

- 保价：申报金额 × 0.3%，单票保费上限 8,000 元；保费超上限的报价**不能确认**，需降低申报金额或分票
- 代收货款、送货上门：各 30 元/票，两者互斥不能同时选
- 金额内部以"分"计算，避免浮点误差

## 版本约定

- 每个版本生成时即物化服务选择与费用明细，确认后固定不变
- 确认后客户增减项目 → 生成新的待确认版本，原已确认版本继续有效
- 撤下待确认版本 → 版本标记"已撤下"并保留，原报价不受影响
- 新版本确认后，旧的已确认版本转为"已替换"留档

## 分层结构

- `src/domain/`：明细规则与报价版本生命周期（纯函数，不依赖框架）
- `src/storage/`：localStorage 存取
- `src/stores/`、`src/components/`、`src/App.vue`：页面层

数据默认保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。
